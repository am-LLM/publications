# Publication Drafts

This directory contains two scientific manuscripts and the public artifact manifest for Tiny Wonder / LoRA Lens Lab.

- `paper1_zero_base_host_draft.md`
- `paper2_stacking_attenuation_draft.md`
- `publication_artifact_manifest.md`
- `tools/publication_hygiene.py` — small standard-library release scanner; run it against an explicit staged public directory before packaging. It does not follow symlinks or write inside the staged directory.
- `submission/` — anonymous IMRaD PDFs, reproducible PDF builder, and package notes.

The manuscripts use standard scientific structure. Internal engineering workflow names and private machine paths are intentionally excluded. The current evidence-integrated drafts preserve explicit limitations: exact reference-protocol reproduction, independent adapter-training repetitions, exhaustive order permutations, and no cross-host absolute-PPL comparison.
